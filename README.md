Fitur Penjual
Menambahkan produk khusus promo poin.

Memilih produk yang dapat ditukar atau dibeli menggunakan poin.

Menentukan jumlah poin yang dibutuhkan.

Mengatur pilihan pembayaran: poin penuh atau poin + uang.

Menentukan stok dan kuota produk promo.

Mengatur periode berlaku promo.

Mengedit, menonaktifkan, atau menghapus promo.

Melihat daftar transaksi produk promo.

Fitur Pembeli
Melihat katalog produk promo poin.

Melihat syarat, periode, dan stok promo.

Melihat kebutuhan poin serta tambahan uang jika ada.

Menukar poin untuk mendapatkan produk promo.

Melihat riwayat penukaran poin
